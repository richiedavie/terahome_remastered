# Terahome

**Terahome** is a fictional Indonesian home internet service provider (ISP) landing page built with Astro, TypeScript, and Tailwind CSS.

The project showcases a professional, single-page marketing website for a fiber optic broadband provider targeting residential customers.

---

## About Terahome

Terahome offers fiber optic home internet services designed to support everyday digital activities for Indonesian families — from basic browsing to 4K streaming and competitive gaming.

### Core Service

- **Fiber Optic Internet** — All packages run on a stable fiber optic connection
- **Unlimited Data / Tanpa Kuota** — No data caps across every plan
- **Free Router Rental** — Every package includes a free Wi-Fi router (quality scales with tier)
- **24/7 Support** — Customer support available around the clock

### Key Features

- **Kecepatan Stabil** — Stable speeds on fiber optic infrastructure
- **Unlimited Data** — No quotas, no throttling
- **Coverage Luas** — Wide signal coverage across the home
- **Gaming & Streaming** — Low latency, lag-free experience for gaming and video streaming
- **Gratis Sewa Router** — Free router rental included, scaling from standard to premium by tier
- **Support 24/7** — Tiered customer support: Standard → Prioritas → VIP
